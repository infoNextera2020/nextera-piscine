# ATM reporting oracle and trusted-capture source contract

31 October 2026. The reporting choice is owner approved and implemented in the [actual learner handoff](../week1-atm-single-main-proposal-20261031/learner-pack/learner-en.md) and [single main.go starter](../week1-atm-single-main-proposal-20261031/learner-pack/main.go). This developer directory contains the independent model, strict observation parser, minimal capture-source seam and tests. It is not linked as a learner solution, has no full runnable ATM/reference program and enables no live grader or publication.

The supplied Report helper emits the six documented stdout JSON arrays. Human prompts/menus/explanations use stderr with flexible wording. Null is for rejected/end before login; authenticated end reports include the current committed balance, even EOF during an amount request. The exact original ReadLine/state region, original input demo, required README information and business rules remain intact. [The reporting contract](projection-contract.md) is visible in the learner assignment, not hidden in tests.

`prototype/oracle.py` independently computes the expected trace from exact whole-line input and compares every ordered event/value. The helper only serializes structurally valid facts; it cannot certify the business state. Unknown/missing contract selection stays unresolved, incomplete observations stay incomplete, and matching observations never become an academic PASS here. No numbers are scraped from prose and no learner code is modified or instrumented.

`prototype/capture.py` adds only a host-owned interface and binding checks. It requires exact executed-source/input hashes, an immutable attempt/capture identity, host reporting-contract and explicit resource-policy hashes, complete I/O and clean host-observed termination. A learner JSON object or a “verified/passed” flag cannot supply a capture. There is deliberately no configured production producer, native read, credential, service or HTTP receipt endpoint; missing authority returns unavailable. Data-shape/digest checks alone are not origin authentication. Future Runner integration must establish that host boundary independently.

`prototype/report_helper_test.go` verifies the supplied serializer, null/zero distinction, structural rejection before writing, stdout failure and preservation of learner state. Existing ReadLine tests are reused from their exact retained private artifact. Pure Python tests cover business/reference examples, grammar-negative cases, historical ambiguity witnesses and fake-capture failures. The Go report demo uses fixed sample values only; it is never treated as an ATM solution or a genuine captured assessment.

The original [counterexamples](counterexamples.md) explain why the added framing was needed and why invisible source assignments cannot be certified from stdout. Free-prose clarity, source invariants, honest README checks and team participation are not claimed by the oracle and still require exact-attempt review. Neither that review nor local helper success replaces the platform's automated-result gate.
