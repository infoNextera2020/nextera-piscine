## Exact protocol mapping

ABI4 has exactly the existing six execution-contract fields: `version: 4`, `item_key: <project node key>`, `learner_file: main.go`, `function: ""`, `input_type: stdin_utf8`, `output_type: atm_report_events_v1`. It submits raw main.go; it is not the ABI1/3 function harness or ABI2 exact-stdout comparator. No model, expected cases or oracle code is inserted into the learner container or public source resources.

The only extra wire binding is `semantic_profile_digest` at each protected catalog test-pack root, resolved evaluation-spec root and private metadata root. It is required for ABI4 and must equal the computed approved source profile `f09da2b66999409f6dc08ea8f54ef5c34ac259d48cccf5b1d66ecb63ad4c1007`. It is absent and forbidden for ABI1/2/3, including explicitly null/empty fields. It is forbidden inside execution_contract. Existing runner-image digest binds the trusted model implementation; no duplicate model-source fixed-point digest is introduced.

ABI4 requires explicitly supplied `case_generation: {mode: static}` with no seed/generator extras. Runner-owned private cases are exact input-only rows `{input: <UTF-8 string>}` in cases/public.json and cases/private.json; expected/unknown/duplicate fields are rejected by that separate evaluator. The host independent model derives the full ordered trace from exact delivered stdin. No pack/learner self-PASS or expected-output assertion is authoritative. Public Run remains outside authoritative grading and is unchanged.
