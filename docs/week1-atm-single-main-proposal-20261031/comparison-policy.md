# Approved ATM observation comparison policy — source only

The owner-approved reporting addendum makes the objective observation boundary explicit in [the actual learner assignment](learner-pack/learner-en.md). It preserves arbitrary clear human wording on stderr while stdout is reserved for the supplied Report helper's structured arrays. This closes the original free-prose framing ambiguity without hidden labels, digit scraping, source rewriting or new business behavior.

The independent reference model derives the whole expected ordered trace from exact stdin under the retained rules. Record kinds and current balances are candidate output, not declarations of correctness. A structurally valid Report("balance", &wrongBalance) remains wrong if its value differs from the independent model. Every authenticated terminal observation includes the committed balance; pre-login rejected/end records use null. Menu readiness and pending amount phases are explicit, so missing/extra/reordered/stale facts cannot be silently ignored.

Only output line endings, line-edge whitespace and blank lines are presentation normalization. Input remains exact: PIN 0427 as text; exact menu tokens; one-to-five ASCII-digit amounts, no trim/sign/decimal/prefix acceptance, leading zeros allowed only within the original amount length; three failed PIN lines, integer amounts 1..1000, balance 0..10000 and unchanged state on rejection. No new numbers, scores, deadlines or retry/resource defaults are introduced. Original historical source labels are retained.

All original business examples remain in the full learner brief. The pure prototype tests those cases plus invalid text, limit boundaries, repeated menu/balance observations, insufficient funds, whole cap rejection, earlier successful state surviving rejection, EOF at every phase, CRLF/final lines, wrong event/value, malformed JSON, nonfinite/bool/float/null confusion, extra/missing/reordered records, numeric/prose collisions and absent/incorrect capture authority.

Future authoritative comparison requires host-bound executed source bytes, exact delivered stdin, reporting-contract digest, explicit resource-policy digest, complete separate stdout/stderr capture and a clean observed process exit. Shape checks on learner JSON do not establish that authority. The source-only capture seam has no production producer and returns unavailable without one; it does not award grades. Infrastructure interruption is incomplete/unknown rather than a fabricated successful assessment.

The old arbitrary-prose ambiguity and invisible internal-state counterexamples remain documented historically. The new records make terminal observations testable but cannot prove a private assignment after the last output; source/explanation/team criteria still require exact-attempt review. No helper, demo or manual fallback substitutes for required automated evidence or mentor decisions. Live grader/testpack publication remains inactive.
